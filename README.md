# The Digital Battlefield

**An interactive guide to how social media shapes political crises**, anchored in South Korea's martial law crisis of December 2024.

This project is an interactive companion to a blog article on political crisis communication. It brings together concise theoretical lenses, an actor-network diagram, a crisis-escalation flowchart, a case-study timeline, and five principles of effective crisis communication.

## Explore the experience

The page includes:
- **Three analytical lenses:** agenda-setting, framing, and information disorder.
- **Interactive communication ecosystem:** select an actor to explore its role and information flows.
- **Crisis escalation flowchart:** switch between verified and unverified information pathways.
- **Case-study timeline:** key events in South Korea in December 2024.
- **Five communication principles:** speed, accuracy, transparency, consistency, and empathy.
- **Light/dark theme** and responsive layouts.

## Run locally

No build step or package installation is required.

1. Clone this repository.
2. Open `index.html` in a browser.

## Publish with GitHub Pages

1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then save.
4. After GitHub Pages finishes deploying, the site will be available at:

   `https://jyatin.github.io/digital-battlefield/`
